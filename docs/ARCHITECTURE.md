# Architecture — Milestone 1 visual pass 2
Version 0.1.2. Vite / JavaScript ES modules / Phaser 3 HTML5 Canvas. The DOM remains only a full-viewport host. All menus, HUD, dialogue, shops and controls are drawn by Phaser. No backend or runtime remote assets.

## World and presentation
- `src/data/mapLayouts.js`: 2240x1152 world extents and per-location paths, buildings, props, water, fences, fields, signs and townspeople. Physical footprints are derived alongside scenery, avoiding separate hand-maintained renderer/collider positions. Traversable borders leave a visible vegetated frame. Cosmetic flowers/grass, tiny stones, butterflies and NPCs do not block movement.
- `src/data/locations.js`: area metadata, safe spawns and connections, functional shops/bed, optional sign/NPC contexts and `walkable`. It consumes the shared layout footprints. Home is a furnished cutaway house opening into an explorable homestead; its east gate connects to Farm. The six existing crop beds form one active field, with three visual-only reserved fields. Town has a west market, civic square, residential lanes and a closed future shop.
- `src/scenes/displayScale.js`: responsive Wide policy. Camera zoom 1.5 desktop / 1 compact (3x / 2x source-pixel display). No cover calculation. This exposes ~26.7x15 tiles at 1280x720. UI is independent 2x. All requested viewport extents fit inside the drawn maps.
- `src/scenes/WorldScene.js`: local asset loading, keyboard/touch movement, collision queries, nearby contexts, bounded following camera, night tint and hooks for presentation. Speed is 260 world units/sec (previously 190); walking remains free. Position updates and diagonal normalization retain the working rules.
- `src/art/worldArt.js`: compose the normalized environment atlas at two world units per source pixel. Union path rectangles into terrain cells with edge/corner tiles; render buildings/trees using feet depth; draw existing crop state. Water and fountain references are handed to the atmosphere module.
- `src/art/Atmosphere.js`: bounded decorative butterflies, two-frame water/fountain animation, brief footstep dust and an interaction marker flash. These never change save state, crop growth or energy. Effects pause with gameplay; scene rebuilds kill their tweens.
- `src/entities/PlayerView.js`: retained animation/facing contract, now loading original 16x24 frames from processed assets. Idle + two walking poses in each of four directions. Radius-12 foot collision remains independent of sprite size.
- `src/ui/{interface,Hud,pixelWidgets}.js`: separate canvas UI Scene, fixed compact HUD, menus, readable contextual prompts and touch buttons. App `use` routes optional dialogues separately from functional shops. Location/subtitle notices appear on each transition.
- `src/main.js`: lifecycle, transactions, local save, pause and dialogs. `src/ui/styles.css` keeps fullscreen/no scrolling. No visible DOM panels.

## Save and gameplay contract
`src/systems/{state,save,farming,economy,time}.js` and `src/data/crops.js` are unchanged from the prior release. The same key `simple-life.save.v1`, version 1, six crop indices, price/yield/growth/watering rules, day length, health/energy and inventories are retained. The new map geometry is the only reason a stored position may become unsafe. Existing validation already relocates an unsafe position to that area's safe spawn; all normal progress is preserved. Safe legacy coordinates load unchanged. No reset/migration of crops or progress is needed. New Game still confirms before replacing progress.

## Asset pipeline and build boundary
Primary external pack: Kenney Tiny Town 1.1, CC0 1.0. Untouched official archive is in `public/assets/vendor/kenney/tiny-town/`. Evidence is under `docs/assets/licenses/`. `scripts/process-town-assets.py` reads that archive, selects 49 source tiles, applies the documented palette lookup, composes structures, and packs a 45-frame atlas alongside original missing props. It also authors smaller original boy/girl sheets and three original NPC colour variants. `public/assets/pixel/processed/manifest.json` identifies every selected tile, transformation and original addition.
The original `world` atlas/font and `scripts/generate-pixel-assets.py` remain for furniture, crop/water art, shops and UI. Their historical 24x32 sheets are source history, not shipped. `vite.config.js` disables wholesale public copying and emits an explicit eight-file runtime asset list. Vendor archives, pack previews, unused individual files, manifest and source tools are excluded from `dist/`. All runtime assets are committed; Python/Pillow are needed only to regenerate art, never to run/build the game.

## Verification
Node rules tests plus layout reachability, responsive tile/player scale and unsafe legacy-position preservation tests. Browser suites exercise real keyboard, pointer and CDP touch input in disposable contexts. Full loop uses actual inputs; the exploration/legacy suites use separate initial test fixtures and then real controls.
DEV or production `?qa` exposes cloned read-only snapshots of state, contexts, canvas control rectangles, camera and player frames/height. No gameplay mutation hooks. Normal production URL exposes no QA object. Reports/screenshots are under `docs/verification/pass2/`; previous-pass evidence is retained separately.
