# Technical notes
Version 0.1.0; Phaser 3.90.0; Vite 6.4.3; JavaScript ES modules; explicit Canvas renderer. Production output in dist/ is a static HTML/CSS/JS build with relative asset paths. No server application or external runtime asset services.
Runtime requests: same-origin HTML/CSS/JS only. No API, auth, analytics, advertising, telemetry, automatic downloads or personal-data collection. The development server uses a local Vite HMR WebSocket only.
Local save: simple-life.save.v1, JSON schema version 1. Saves character, location, safe position, day/time, money, health/energy, selected tool, inventory, crop progress and watering, sales count. Invalid fields default/clamp; unknown versions are rejected without crashing. Storage exceptions surface a warning; persistence cannot work when the browser denies storage. Menus/hidden tabs freeze simulation.
Responsive 16:9 world plus HTML interface at desktop 1280×720 and mobile 360×640 / 640×360. Mobile touch pad/buttons; desktop keyboard/mouse. Target browsers Chrome, Edge, Firefox and Safari. See PROJECT_STATUS.md and VERIFICATION.md for actual test coverage rather than treating this target list as certification.
The repository contains original source, pinned lockfile, npm scripts, deterministic system tests and optional Playwright browser scripts. Browser scripts use a dedicated browser/session and require Playwright separately; they are not runtime dependencies.
Build size approximately 1.5 MB uncompressed (about 351 KB summed gzip assets). No runtime art downloads. Phaser is split into a vendor chunk. Final build ZIP/official HTTPS deployment and competition submission remain later release work.
