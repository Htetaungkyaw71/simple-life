# Technical notes — craftsmanship pass
Phaser 3.90.0 / Vite 6.4.3 / JavaScript ES modules. HTML5 Canvas renderer, fullscreen RESIZE, pixelArt, antialias false, rounded pixels and nearest texture filtering. Terrain is 16px source / 32 world units; world camera zoom is 1 for stable 2x pixels. UI is independently 2x. Maps are 2240x1152 with bounded follow camera. There are no visible DOM game panels.
Runtime requests are same-origin HTML/CSS/JS/PNG/JSON/XML only. No backend, accounts, analytics, APIs, tracking or downloaded runtime content. Dev uses Vite HMR. A build allowlist emits eight runtime art files, excluding the untouched vendor archives and all unused pack files. About 1.6 MB uncompressed, mainly Phaser.
Save key/schema remains simple-life.save.v1/version 1. Farm crop indices, economy, growth, watering, day length, energy and validation are unchanged. Map collision footprints now cover expanded scenery; an unsafe old position alone relocates to the area's safe spawn. Valid positions and all normal progress remain intact. Six existing planting beds belong to the active field; the three additional fields are decorative and do not alter state arrays.
Node tests cover rules, map reachability, camera/player scale and position fallback. Browser suites use isolated contexts, actual inputs and read-only QA snapshots (only dev or production ?qa). Five viewport sizes use Chromium emulation; physical phones/notches and other engines remain pending. No success claimed for untested browsers.
Optional art regeneration: Python/Pillow scripts/generate-pixel-assets.py (original atlas/font) and scripts/process-rpg-assets.py (CC BY 4.0 Serene Village adaptation and original missing sprites). They are not needed for npm install/build. Serve dist over HTTP/HTTPS; relative paths support subdirectory hosting. No publishing/submission in this task.
