# Technical notes — 0.1.1
Phaser 3.90.0 / Vite 6.4.3 / JavaScript ES modules. Explicit HTML5 Canvas renderer, full viewport RESIZE, pixelArt true, antialias false, roundPixels true, nearest-neighbour texture filtering. Integer world/UI scaling; camera bounds cover only fully drawn terrain. No external visible DOM game interface.
Runtime: same-origin HTML/CSS/JS and original local PNG/JSON/XML pixel assets only. No backend, APIs, auth, analytics, advertising, automatic downloads or personal-data collection. Development alone uses Vite's local HMR WebSocket.
Local save: unchanged simple-life.save.v1 schema, including character, safe position, location, day/time, stats, money, tools, inventory, crop growth/watering/dryness and sales count. Validation and error handling remain unchanged. No migration needed for version 0.1.0 saves. Menus and hidden tabs pause the simulation.
Tested fullscreen sizes: 1440×900, 1280×720, 1024×768, 390×844, 844×390. Chromium desktop/mobile emulation tested; physical phones and other engines pending. See VERIFICATION.md for evidence and limits.
The pure-system tests need only Node. Optional browser tests use Playwright in a separate QA environment and interact through actual input events. Dev and production URLs with ?qa expose cloned read-only observations; no gameplay mutation API. Normal production URL omits these observations.
All raster assets are committed, so npm ci/build require no Python. Optional asset regeneration uses Python/Pillow; source and licence evidence are retained. Production build is about 1.6 MB uncompressed, dominated by Phaser. Serve dist/ over HTTP/HTTPS; relative paths support static subdirectories. Final hosting/ZIP/submission work is not performed here.
