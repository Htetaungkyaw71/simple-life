# Morning rooster — source and permission record, 2026-10-11

The user requested a chicken sound when waking in the morning. Their five audio packs were searched; none contains a rooster/chicken call. Selected **Medium rooster crowing**, credited **alys**, from [the Wikimedia Commons file description](https://commons.wikimedia.org/wiki/File:Medium_rooster_crowing.ogg). The uploader's permission section records the author's public-domain dedication and unconditional any-purpose permission where dedication cannot apply. We retain the file page's published creator credit, alys, without claiming Codex authored the recording.

Evidence: rooster-source.html is the reviewed source/permission page; Medium_rooster_crowing.ogg is the unmodified recording; source-url.txt gives its exact media URL. Manifest.json records both source and runtime SHA256s, attribution, permissions, processing and duration. Existing Farm sleep/rustle effects keep their embedded permissions and hashes under ../cozy-audio. No musical wake jingle is used.

Offline scripts/import-morning-audio.py decodes the retained 8.306938775510204-second recording with FFmpeg, converts to mono PCM16/22050 Hz, removes DC, applies 10ms start/40ms end fades and limits RMS to .08 and peak to .35. It preserves the natural crow and surrounding hen clucking; no looping, music, speech or AI generation is added. Processing runs offline using existing FFmpeg/Python/NumPy; no new runtime dependency. The converted WAV is public/assets/audio/cozy/sfx-rooster.wav, the sole selected member distributed in the playable game. Sources/evidence/Ogg/HTML stay outside dist. Normal builds need none of the source downloads or processing tools.
