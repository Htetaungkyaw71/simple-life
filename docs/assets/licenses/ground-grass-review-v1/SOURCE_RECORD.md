# Ground grass review v1 — source and AI record

Date: 2026-10-21

The user supplied two screenshots of this project and three third-party visual references. The project screenshots define current scale, palette and fit. The three references were used only for general warm-olive mood and density; no reference tree, plant, layout or UI was requested or copied. The original screenshot files remain outside the production build.

Six separate OpenAI built-in image-generation calls were used: one initial call for each A/B/C full-canvas lawn, followed by one focused correction call for each after the fit check found the first pass too bright and noisy. The service does not expose a model version. Every call requested one asset, not a sheet. Final correction prompts kept the full-bleed top-down lawn, shifted it to the sampled darker/yellower game lawn, enlarged and flattened the cloud patches, removed roughly 70% of tuft/noise detail, limited cream flecks, prohibited copied objects/layout/UI, and supplied this exact eight-color lawn list: `#687749 #748455 #7F9056 #879564 #8E9C67 #98A66B #F0E8C7 #D8C995`. Every prompt also required: “crisp square pixels, no anti-aliasing, no blur, no gradients, no dithering noise, no JPEG artifacts, no text, no watermark, drawn as if on a 128x128 pixel canvas, uses only the colors I list.” Variants differ only in patch flow and open-space density.

`scripts/ground_grass_review.py` performs the local deterministic stage with Pillow and NumPy: separate screenshot palette statistics, center square crop, 128×128 nearest-neighbor resize, nearest locked-palette mapping without dithering, hard center-cross seam repair by copying nearby pixels, exact-edge checks, repeat preview and fit comparisons. Each final texture is RGB 128×128, has one fully opaque component, no pinholes, only locked colors and byte-equal opposite edges. Exact hashes are in `output/art/ground-grass-review-v1/checks.json`.

This is AI-generated/adapted artwork, not CC0, exclusive, human-only artwork or a guarantee of competition eligibility. Final rights and visual acceptance remain the human team's responsibility. After user approval, the three final PNGs were copied byte-identically to `public/assets/pixel/processed/grass-ground-{a,b,c}.png` and added to the explicit production allowlist. Runtime hashes are recorded in `runtime-install.json`. Only ground rendering changed: gameplay, collisions, harvesting, saves, UI, backend, deployment, push and publication remain unchanged.
