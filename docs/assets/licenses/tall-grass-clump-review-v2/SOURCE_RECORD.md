# Tall grass clump checkpoint v2

Three original review-only clump sources were made with the OpenAI built-in image generation tool, one call per sprite. The current clump was a problem reference; game screenshots were style/mood references only. Processing removed magenta, retained one connected object, resized with nearest-neighbor, locked pixels to the approved five-color clump palette, and saved final-size scale-1 PNGs. Nothing was copied into `public/` or registered in Phaser.
