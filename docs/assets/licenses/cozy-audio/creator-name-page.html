Hi, I'm Spaceyyy :)

I make cozy pixel worlds for small games: tiles, tiny characters, music loops and soft sounds. Every set is drawn in code on one fixed palette, and the music comes from my own little sequencer, so the packs in a set all fit together. Packs start at $1. Try one, and if it fits your game, the bundles have the whole set.

Thank you to everyone who tried a pack!
