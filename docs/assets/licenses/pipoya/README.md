No payment, account, executable or character generator was used.

Official free file: `PIPOYA FREE RPG Character Sprites 32x32.zip`, itch upload 4257933, listed 2021-08-04; 1,414,743 bytes, SHA-256 `902dd6f9022da851af8510c0a7a19fa9a06c38d1201c23d86723d8d5a1f75c33`. No separate licence text is present inside this ZIP, so the creator page controls. The archive is kept outside the repository (`/tmp/pipoya-characters.zip` during development); the full asset pack, unused characters and source sheets are not redistributed here or in builds.

Eight human sheets are selected under `PIPOYA FREE RPG Character Sprites 32x32/{Female|Male}/`: Female 03-1, Female 17-1, Female 19-1, Male 02-1, Male 10-1, Male 12-1, Male 13-1, Male 01-1 (all `.png`). Each 96×128 sheet has three native 32×32 cells per row, directions down/left/right/up. Selected cells become 96 named `resident-{0..7}-{direction}-{0..2}` game frames in the existing mixed game atlas, displayed at integer scale 2. Saturation reduced 28%, brightness reduced 4%; contours, faces, native animation cells and alpha preserved. No resampling, preview extraction, weapon/monster/animal art or original sheets included.

This integration is use inside a game; it does not offer the standalone pack for download. Its custom terms remain distinct from the CC BY building art and original project additions. In-game Credits includes a separate Pipoya source/terms page. Regeneration: obtain the official free ZIP, set `SIMPLE_LIFE_PIPOYA_ZIP` to its external local path, and run the established asset pipeline or `scripts/extend-city-art.py` with Pillow. Builds only consume committed atlas cells. No claim that the mixed atlas is freely redistributable as an asset library.
