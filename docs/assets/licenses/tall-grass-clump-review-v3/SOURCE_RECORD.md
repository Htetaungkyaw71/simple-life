# Tall grass clump checkpoint v3

Three original clumps were created in separate OpenAI built-in image-generation calls. The gameplay screenshot was a color/pixel-density/mood reference only. Each prompt requested one 10–14-blade sprite drawn as if on a 48×48 logical canvas over solid magenta. Processing detects the large-preview logical cell cadence, uses majority-vote per cell, retains one connected object, fills enclosed alpha holes, locks the five-color palette and writes final scale-1 canvases.

The user approved this set on 2026-10-21. The second wide candidate, with fewer and broader blade groups, is selected. `runtime-install.json` records the three source hashes and the resulting allowlisted `public/assets/pixel/processed/grass-clumps.png` hash. Runtime placement is display-only and preserves the prior vegetation record, harvesting point, collision and save identity.
